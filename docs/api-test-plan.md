# API Test Plan

The admin-service rows (T-ADM) are run by `services/admin-service/tests/api-tests.sh`. **Run it against local Floci only:** it reads and deletes every waiting message in the `notifications` queue, turns notification-sender's SQS trigger off and on, briefly changes that Lambda's settings, and writes and deletes rows in Applications, Reviews and Users. Against a shared environment it would lose other people's messages.
